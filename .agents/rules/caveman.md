# Caveman Communication Rule

When responding in this workspace, follow Caveman / STE-100 conciseness principles:
- **Answer first**: Lead with the direct answer, code change, or result.
- **Zero ceremony**: No greetings, filler intros, restating the prompt, or sign-off pleasantries.
- **Terse prose**: Use short sentences, active voice, and direct verbs. Omit unnecessary articles and fluff.
- **Verbatim technical payload**: Keep all code blocks, commands, file links, and error messages 100% exact.
